Update groups

An update group is a set of Compose services, in any stacks and on any hosts, that update together and in order, such as an identity server and the proxy outposts that must never run ahead of it. A service joins one with the container labels baseline.update.group=<name> and baseline.update.order=<n>, or on its stack's page; the labels win. Every Compose update that touches a member (by hand, auto-update or a patch group) updates the group's members with it, lowest order first, each after the ones before it succeeded. Groups don't mix environments: a Dev and a Prod stack with the same group name are in separate groups.
