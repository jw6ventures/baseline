Move to a new tag

The members run different images that share a tag ({{with $v.Tag}}{{.}} now{{else}}none yet{{end}}). Moving the group writes the new tag into each member's image in its Compose file, on the host, then pulls and recreates it: the leaders first, then the rest in order. A member that doesn't come up healthy is rolled back, Compose file included, and the members after it are skipped. Only tags written in the Compose file itself can be moved, not ones set through a variable.
