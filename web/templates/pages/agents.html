Agent releases

The server publishes the agent binaries built into its image as a signed release each time it starts, and keeps the last 5 versions. An agent checks a release's SHA-256 and its signature against the release key it pinned at enrollment, keeps its current binary, and puts that back by itself if the new one doesn't reach the server within 5 minutes.
